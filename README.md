# יומן אירועי בטיחות

אפליקציה מקומית לממונה בטיחות. התהליך כולל הדבקת דיווח או טעינת סריקה בכתב יד, חילוץ לטיוטה, בדיקה מול המקור, תיקון ושמירה. אפשר גם להזין אירוע ידנית. לוח המחוונים מסנן לפי מחלקה, סוג אירוע ואיבר שנפגע.

## התקנה והרצה ב-Windows

1. הורד את קוד המאגר באמצעות **Code → Download ZIP** וחלץ את הקבצים.
2. התקן Python 3.11 ומעלה. פתח PowerShell בתיקייה המחולצת והרץ:

   ```powershell
   py -m pip install -r requirements.txt
   py server.py
   ```

3. פתח בדפדפן את [יומן אירועי הבטיחות](http://127.0.0.1:8765). השאר את חלון PowerShell פתוח בזמן העבודה. לעצירה לחץ Ctrl+C.

## חילוץ מטקסט ומסריקות

התקן [Ollama](https://ollama.com/download/windows), הפעל אותו והורד את מודל הראייה המקומי פעם אחת:

```powershell
ollama pull gemma4:e4b
```

לאחר ההורדה, החילוץ זמין דרך Ollama המותקן במחשב. אפשר לעבוד ידנית, לייבא אקסל ולהשתמש בלוח המחוונים גם בלי המודל. המודל מקבל את הדיווח רק בכתובת loopback. מומלץ לכבות את תכונות הענן של Ollama לפי [ההגדרות המקומיות](https://docs.ollama.com/faq) אם ההתקנה משמשת במחשב בית החולים.

הסריקה יכולה להיות PDF של עד שמונה עמודים או תמונת PNG/JPG בנפח עד 24MB. טען דיווח אחד בכל פעם. בדוק את התמלול ואת פרטי הטיוטה מול המקור. אפשר לתקן את התמלול ולחלץ ממנו טיוטה מחדש. האפליקציה שומרת את השדות שאושרו. קבצי הסריקה והתמלול הגולמי עוברים בזיכרון במהלך החילוץ.

## עבודה עם הטבלה הקיימת

בחר **ייבוא אקסל** והעלה את קובץ ה-XLSX. האפליקציה מאתרת את שורת הכותרות של הטבלה הקיימת באמצעות ״מספר אירוע״ ו״מהות האירוע״. לפני האישור יוצגו מספר האירועים והנפגעים שזוהו. מספר אירוע משותף מקבץ שורות נפגעים לאירוע אחד. מספרי אירוע שכבר קיימים מדולגים כדי למנוע כפילויות. אם אין נתוני היעדרות, השדה נשאר ריק. ״ייצוא כל הרשומות״ מפיק גיליון Excel באותו מבנה בסיסי ומוסיף את שדות חומרת הפגיעה, מחלקת האירוע ואימות אירוע ללא נפגע.

סינון משולב לפי מחלקה ואיבר מחפש התאמה באותה רשומת נפגע. מספר האירועים בסיכום סופר כל אירוע פעם אחת. אירוע הכולל נפגעים מכמה מחלקות יכול להופיע בכל אחת מהן בגרף המחלקות. סכום ימי ההיעדרות מחושב מהערכים שתועדו, ומוצג לצד מספר הנפגעים עם נתון.

## הנתונים במחשב

מסד הנתונים נשמר בתיקיית המשתמש בנתיב `%LOCALAPPDATA%\SafetyRegister\incidents.sqlite3`. אפשר להגדיר תיקייה באמצעות משתנה הסביבה `SAFETY_DATA_DIR`. לגיבוי, עצור את האפליקציה והעתק את מסד הנתונים למיקום מתאים. הקוד שבמאגר אינו כולל דיווחים או שמות.
